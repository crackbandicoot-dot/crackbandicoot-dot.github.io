# Project Beta

**Tech stack:** Node.js, Commander.js, Marked

## Overview

Project Beta is a CLI that converts a folder of Markdown files into a static HTML website. It includes a built-in development server and watch mode for live reloading.

## Features

- Convert Markdown to HTML with front matter support
- Generate a table of contents automatically
- Watch mode for local development
- Deploy-ready output folder

## What I Learned

- Building CLI tools with Node.js
- Parsing front matter with gray-matter
- File system operations and event-driven programming
