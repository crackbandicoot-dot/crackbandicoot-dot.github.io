# Project Alpha

**Tech stack:** HTML, CSS, JavaScript, Firebase

## Overview

Project Alpha is a habit tracker that lets users log daily activities and view progress over time. It uses local storage for data persistence and a simple responsive design.

## Features

- Add, edit, and delete habits
- Daily streak counter
- Visual progress charts (using Chart.js)
- Dark mode toggle

## What I Learned

- Working with local storage
- Building a responsive layout without frameworks
- Implementing a chart library
